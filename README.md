# Emberbound: Endless Descent

**[Play in your browser](https://agentburgundy.github.io/emberbound-play/)**

Become a wizard in an endless pixel-art dungeon. Combine fire, frost, lightning, and wards; face a guardian every five floors; bank earned shards after any battle; and unlock 130 cosmetic pieces, including 30 elaborate Legendary and Mythic pieces.

- **Phone/tablet:** tap spell buttons; tap the dungeon to blink.
- **Computer:** use 1–4 for spells, arrow keys to blink, and Escape to pause.
- The first load downloads about 50 MB. Progress saves locally in the current browser. Browser progress does not transfer to another device or to the iOS app.
- This is a free single-player browser edition. Apple Game Center, AdMob ads, and App Store purchases are iOS features.

The site automatically deploys from this repository's `main` branch through GitHub Pages. This repository contains the compiled web player; the Unity development project is maintained separately.
